# 🤖 AI-Powered Job Recommendation System

## 📌 Overview
This project is an AI-based job recommendation system that suggests relevant jobs to users based on their skills, interests, and profile data.  
The system helps users find suitable job opportunities quickly and efficiently.

---

## 🚀 Features
- 🔍 Smart job recommendations based on user input   
- 🧠 AI-based matching logic  
- 📄 Job listings display  
- 💾 Data storage using MySQL  
- 🌐 Full-stack implementation (Frontend + Backend)
